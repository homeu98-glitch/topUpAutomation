# 2026-10-12

## 修復 Vercel Hobby 12 Serverless Function limit
- 問題：Vercel 部署讀 `api/` 目錄，每個有 `export default` 嘅檔自動變成一個 function。`api/` 入面有 35 個 route handler + index.js → ≈36 function，爆 Hobby 上限 12。之前嘅 `server.js` Express 單體根本冇被 Vercel 用（有 `api/` 喺度就行 Serverless Functions mode，ignore root server.js）。
- 解法：將 35 個 route handler 由 `api/` 搬去 root `routes/`（保留 tree，內部 `../lib`/`../../lib` 相對路徑深度唔變）。`api/` 只留 `index.js` 做單一 catch-all function。
- import 路徑改動：`server.js` → `./routes/...`；`api/index.js` 動態 import → `../routes/...`；`public/*.js` 嘅 `/api/...` HTTP 路徑唔使改（catch-all 照 handle）。
- `vercel.json` 個 cron `/api/cron/auto-approve` 經 catch-all 處理，唔受影响。
- 結果：Vercel 只會部署 1 個 function（≤12）。`node --check` 兩個 entry 檔都 pass。
- 注意：Hobby 嘅「單次部署最多 12 function」硬上限至今未改（2025-2026 改嘅係 CPU/記憶體/呼叫次數計費模型，唔係 function 數量上限）。
