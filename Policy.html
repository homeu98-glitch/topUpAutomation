Privacy Policy for MacauPay Transaction Grabber Last Updated: 2026-07-03 1. Introduction (簡介) This Privacy Policy explains how the MacauPay Transaction Grabber ("the Extension") handles your information. The Extension is designed as a tool to help users synchronize their own transaction data from the MacauPay merchant back-office to their private database. 2. Data Collection and Access (數據收集與存取) The Extension only accesses data from the specific website: https://msp.macaupay.com.mo/. When active, the Extension collects the following transaction-related information: • Transaction order numbers (pay_order_no, trade_no, order_no) • Order amounts and currency • Transaction timestamps • Store/Merchant names • Transaction status details 3. Data Usage and Transmission (數據用途與傳輸) • Purpose: The collected data is used exclusively for the user's personal or business record-keeping and automated reconciliation. • Transmission: Data is transmitted via secure HTTPS connections directly to a database (Supabase) specified and controlled by the user. • No Third-Party Sharing: We do not sell, trade, or share your transaction data with any third parties. We do not have access to the data you synchronize to your database. 4. Data Storage and Security (數據儲存與安全) • Local Storage: The Extension stores user-configured settings (such as Machine ID, Sync Intervals, and Start Dates) and a temporary cache of the last successful grab in the browser's chrome.storage.local. • Authentication: The Extension relies on the user's existing active session on the MacauPay website. It does not store or see your login password. • Encryption: Data sent to the user's database is encrypted using standard SSL/TLS protocols. 5. User Control (使用者控制權) • Users can stop data collection at any time by clicking the "Stop" button in the Extension popup. • Users can clear all local settings by uninstalling the Extension. • Users have full control over the destination database (Supabase) where the data is stored. 6. Compliance with Chrome Web Store Policies (合規性聲明) In accordance with the Chrome Web Store User Data Policy, we declare that: • We only request permissions that are necessary to implement the core features of the Extension. • We do not use the data for advertising, marketing, or any purpose other than the core functionality described above. 7. Contact (聯絡方式) If you have any questions about this Privacy Policy, please contact the developer via the support link provided on the extension's listing page.
